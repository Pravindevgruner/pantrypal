Module 1: Customer Module
Fulfilled & Verified
Architecture & Implementation:
  • User registration and login: Implemented via /api/auth/register and /api/auth/login with JWT token generation and BCrypt encryption. Mobile app features native registration and local AsyncStorage credential caching.
  • Browse categories and products: Dynamic category carousels and product catalogs. Products feature pricing, discounts, weights, and high-visibility shelf-life tags (e.g., 5d Shelf Life).
  • Search and filter: Real-time search query matching product names/descriptions, category filter chips, and sorting.
  • Add items to cart and wishlist: State-managed Cart and persistent Wishlist with subtotal, taxes, and delivery fee calculation.
  • Place orders and make online payments: Checkout workflow supporting multiple payment options, automatic order numbering (PP-XXXXXX), and simulated gateway callbacks.
  • Track order status: Multi-stage progress tracking (PLACED → CONFIRMED → PICKED_UP → OUT_FOR_DELIVERY → DELIVERED).
  • View order history: Chronological order logs with item breakdown, pricing, timestamps, and order detail drill-downs.
  • Manage profile and addresses: Profile editing and address book with "+ Add New Address" modal and default selection.

Module 7: Smart Expiry Reminder Module
Fulfilled & Verified Live
Architecture & Implementation:
  • Automatic purchase synchronization: Completed grocery orders automatically transfer items into the user's Smart Expiry tracker with calculated shelf lives.
  • Estimated expiry dates calculation: Category-based shelf life engine (Milk = 5 days, Bread = 7 days, Eggs = 21 days, Apples = 14 days) automatically computes estimatedExpiryDate = purchaseDate + shelfLifeDays.
  • Send reminder notifications: Background midnight cron job checks database daily and sends high-priority notifications for items expiring within 48 hours.
  • Display Fresh, Expiring Soon, and Expired products:
    • 🟢 Fresh (≥ 3 days remaining)
    • 🟡 Expiring Soon (1 - 2 days remaining)
    • 🔴 Expired (≤ 0 days remaining)
  • Food waste reduction analytics: Live waste reduction metrics ("85% Waste Prevented", "₹640 Saved") and recipe suggestions for items expiring soon.
  • Expiry history logs: Historical records of consumed, expired, and discarded items preserved in database (/api/expiry/history).
  • Household grocery inventory management: Dedicated Household Pantry tab with custom item addition, storage zones (Fridge, Pantry, Freezer), and "Mark as Consumed" actions.
